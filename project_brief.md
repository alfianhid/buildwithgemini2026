# My agent: Jessica - Travel & Itinerary Concierge Agent
One-liner: A conversational agent that helps travelers discover destinations and plan personalized day-by-day itineraries with a catalog of curated attractions, activities, and local spots.

Tool coverage:
- Memory: User travel preferences (budget tier, travel pace, favorite cuisines/activities, past visited cities, travel companion setup).
- Tools: Search destinations, lookup attraction details, build/save daily itineraries, calculate budget breakdowns.
- Catalog/UI: Curated destinations, points of interest, and hotel/activity recommendations rendered as rich A2UI cards and schedule tables.
- Image gen: Generates scenic postcard-style destination visuals and activity highlights for trip inspiration.
- Sandbox: Trip budgeting calculations, currency conversion, and distance/timing route estimations.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for budget and schedule calculations, Google Maps / Places API integration, and export to calendar/PDF.
